# Archive: July 2026 IBM Bob challenge material

FINITE was first built as an entry for the July 2026 AI Builders Challenge with IBM Bob. The
entry was not submitted. This folder keeps the planning, release-gate and submission documents
from that period as a historical record. They describe the state of the project in July 2026
and are no longer maintained.
