# FINITE three-minute judge sequence

Target runtime: **2:52-2:58**. Record against the exact submitted tag. Every number on screen must
come from the sealed candidate bundle or a clearly labeled live receipt. Keep `SIMULATION`,
`FIXTURE`, or `LIVE` visible in every technical shot.

## 0:00-0:16 - The missing control layer

**Visual:** an ordinary agent DAG; deadline, provider, token, cost, context, CPU/RAM/network, and
effect constraints close around it.

**Narration:** "Agent frameworks tell us what may run next. They do not make time, capacity,
money, context, or irreversible actions infinite. FINITE turns those promises into an executable
contract."

## 0:16-0:36 - IBM Bob is builder and first client

**Visual:** genuine Bob session history, one material code or test contribution, then Bob's MCP
inventory showing all 22 FINITE tools.

**Narration:** "IBM Bob helped plan, build, and verify this exact release. Bob is also FINITE's
first orchestration client through MCP."

**Hard recording gate:** do not record or narrate this segment until real evidence exists in
`docs/bob-build-log.md`. Never substitute Codex footage, an MCP unit test, or a mock Bob call.

## 0:36-1:02 - Refuse before spending

**Visual:** Physics Console evidence wall and StormShift DAG. Show logical budgets and the physical
coverage matrix. Move to a known impossible deadline or token cap.

**Narration:** "This fictional operations workflow declares deadlines, token and cost caps,
quality, provider limits, CPU, memory, storage, network, RTT, and egress. FINITE checks all of them
before a worker runs. Here the contract is impossible, so it refuses with public numeric facts
instead of spending and hoping. Energy is labeled unsupported rather than estimated."

## 1:02-1:31 - Change the residual plan, keep settled history

**Visual:** launch the bundled workflow paused through the live console. Show replay `VERIFIED`
with zero worker/provider calls; inject a budget cut and a simulated provider 429/reset; then
resume the exact durable revision and stream SSE until `awaiting_effects`. Briefly show the
separate coordinator-crash recovery drill.

**Narration:** "This is the live control plane, not the sealed replay. FINITE admits the run but
pauses before dispatch. A budget cut and provider 429 cross a revision-fenced reducer, replay with
zero model or provider calls, and shed only optional work. It resumes from that exact state and
streams every durable transition. Required work, elapsed time, spend, completed outputs, and
effect boundaries stay fixed."

If the public API is unavailable, use the sealed replay and say: "This is the exact offline replay,
not a live service."

## 1:31-1:52 - Consequential actions stop at intent

**Visual:** `publish_simulated_alert` becomes `PROPOSED`; run state reads `awaiting_effects`; the
console's settled inspection shows `proposed / 0 committed`. Show two runs receiving different
run-scoped intent IDs, then the separate hard-crash simulation drill with physical apply count one.

**Narration:** "Declared writes never enter model or fixture workers. They become durable,
reviewable intents. Exact-scope approval, fencing, and a stable idempotency key keep a simulated
crash from applying the action twice. The demo never contacts Miami-Dade or any public audience."

## 1:52-2:14 - Evidence that attacks itself

**Visual:** whole-run verification and mutation matrix: resource event, artifact, context,
approval, effect, and manifest changes each turn the result red.

**Narration:** "The verifier does not call the planner, a model, a tool, or the live database. It
consumes sealed evidence and checks conservation, causality, lineage, context obligations,
approvals, effect uniqueness, and replay identity. Mutating any identity fails closed."

## 2:14-2:34 - Fair comparison, no benchmark theater

**Visual:** preregistration receipt, identical fixture fingerprint, warmup separation, paired raw
records, confidence intervals, and framework status. Keep PageAgent `not executed` visible.

**Narration:** "FINITE, plain Python, and an exact pinned LangGraph witness run the same fixture
work under one preregistered contract. Raw seeds and failures stay in the denominator. PageAgent
is a browser agent, so this workload is marked non-equivalent and no metric is invented for it."

Only narrate a percentage win if it passes the preregistered threshold at the tagged commit. Show
negative or baseline wins too.

## 2:34-2:48 - Live Granite path

**Visual:** Bob calls `finite_granite_preflight`, `finite_run`, `finite_status`,

**Hard recording gate:** omit this entire segment unless the real SDK path ran and the receipt says

## 2:48-2:58 - Close

**Visual:** v5 social card, public GitHub tag, anonymous or judge-shared demo URL, and short QR code.

**Narration:** "Agents can reason. FINITE makes them keep promises. Keep the promises. Change the
plan."
