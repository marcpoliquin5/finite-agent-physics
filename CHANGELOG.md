# Changelog

All notable project changes will be documented here. The project follows semantic-versioning
intent, but remains pre-release research software until an explicit `v1.0.0` declaration.

## Unreleased

### Added

- Typed workflow contracts, conservative preflight, adaptive scheduling, and refusal evidence.
- Integer resource and provider-quota ledgers with independent replay verification.
- Residual-graph replanning that retains settled work, usage, time, and effect boundaries.

### Security

  fencing, idempotency, and adversarial replay tests.

### Known release blockers
